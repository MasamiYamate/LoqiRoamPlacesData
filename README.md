# LoqiRoam Places Data

[日本語](README.ja.md)

Open place datasets normalized by Loqi, distributed by source and license.

Source records stay separate, and `entity-links/` describes conservative matches
between records without merging them into a single database. AI-inferred labels are
published in separate `loqi-*-ai-enrichment` datasets. They are explicitly marked as
inferences, retain model and prompt provenance, and are not claims of on-site observation.

## Download

Start with [`index.json`](index.json). Each dataset has its own `index.json`, then stores
region artifacts under `regions/<ISO country code>/<region id>/`. JSONL is canonical;
large JSONL datasets are split at record boundaries into numbered `data-*.jsonl`
parts listed in manifest order.
